# Напоминалка (Android)

Приложение с двумя расписаниями уведомлений. Для каждого настраиваются начало, конец, интервал, «за сколько минут предупредить» и текст. Работает в фоне через системные будильники.

По умолчанию:
- каждый час ровно в :00, с 09:00 до 17:00;
- каждые 30 минут, но без целых часов (09:30, 10:30, ...).

## Как получить APK

Сборка идёт в GitHub Actions при каждом push. Готовый файл `Reminder.apk` лежит в разделе **Releases** репозитория. Скачайте его на телефоне и установите (разрешите установку из неизвестных источников).

## Установка поверх старой версии

APK подписан одним и тем же ключом (`app/debug.keystore`), поэтому новая версия ставится поверх старой, настройки сохраняются.
